# Sistema de Librería en Línea - Avance del Proyecto Final

## Descripción del Proyecto
Aplicación de escritorio desarrollada en Java utilizando JFrame (Swing) para la gestión de una librería virtual. Este avance incluye el módulo funcional de inicio de sesión (**Login**) y la estructura inicial del **Catálogo**.

## Integrantes
- Manuel Esteban Arcia Pastrama 

## Módulos Implementados en este Avance
- [x] **Módulo de Login:** Ventana de autenticación con validación de credenciales.
- [x] **Ventana de Catálogo:** Interfaz base para la visualización de inventario.
- [x] **Control de Versiones:** Repositorio en GitHub con commits estructurados.

## Instrucciones de Ejecución
1. Clonar o descargar el repositorio.
2. Abrir el proyecto en **NetBeans IDE**.
3. Ejecutar el archivo principal `LoginView.java` (clic derecho -> *Run File* o presionar `Shift + F6`).
4. Ingresar con las credenciales por defecto (`admin` / `1234`).
